# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting. Do not open a public issue containing exploit details, credentials, personal data or real financial records.

Include the affected component, reproduction steps, impact and any suggested remediation. You should receive an acknowledgement within five business days.

## Scope

This repository is a synthetic-data demonstration. Production authentication, authorization, encrypted persistence, key management, malware scanning, immutable retention and operational monitoring are explicitly outside the demo boundary.
