# Five-minute demonstration

1. Open **Overview** and explain that the KPI is calculated only after normalization, quality controls and deduplication.
2. Open **Data sources** to show the three connector families and select an event to expose its exact source reference and lineage hash.
3. Open **Quality controls** and inspect the arithmetic and future-date exceptions. Emphasize that values are not silently changed.
4. Open **Anomaly lab**, select a finding and read the evidence. Point out the human-review boundary.
5. Open **Audit ledger** to show that event order and payload digests are independently verifiable.
6. Open **Power BI kit** and download the governed fact export.
